# George Lydakis

I build things to explore questions I can't leave alone. Sometimes that's software I use every day; sometimes it's research or a prototype that changes how I think. Then I follow the next question.

## Things I've worked on

- [ShallowSWE](https://github.com/lydakis/ShallowSWE): a benchmark for whether coding agents finish routine tasks, and what each success costs.
- [Alloy](https://github.com/lydakis/alloy): typed AI functions that feel like ordinary Python.
- [Errand](https://github.com/lydakis/errand): your usual commands, run on another machine, without keeping a remote checkout.
- [`agent`](https://github.com/lydakis/agent): a coding-agent runtime built for programs, not people. One daemon, many named bots, JSON events out.
- [IceVault](https://github.com/lydakis/icevault): a macOS app for automated archival backups.
- [Atlas](https://github.com/lydakis/atlas): a sketch of what an operating environment built for software agents would need.

Lately I've been thinking about how AI could help engineers make and verify decisions about the physical world.
